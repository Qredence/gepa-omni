# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for
[Qredence/fleet-gepa-omni](https://github.com/Qredence/fleet-gepa-omni/security/advisories/new).
Do not disclose suspected vulnerabilities in a public issue until they have
been assessed.

## Scope

Reports involving sandbox enforcement, external workspace boundaries, staged
plugin contents, credential handling, and generated-candidate execution are
especially important. Include the affected version, reproduction steps, and
the minimum required permissions where possible.
